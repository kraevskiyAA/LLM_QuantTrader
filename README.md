# LLM_QuantTrader
Implementation of LLM-based copilot for quantitative trading.

## Installation

In this directory run one of the following commands:

```pip install -e .```

or 

```poetry install```

## Basic usage

To run the experiment please see llmqt/inference and run the execution script with the following command:

```python execute_trade.py --config-name "TradingAgent.yaml"```
